# BrickVerse Game

[![License: MPL 2.0](https://img.shields.io/badge/License-MPL_2.0-brightgreen.svg)](https://opensource.org/licenses/MPL-2.0)
[![Godot Engine](https://img.shields.io/badge/Godot-4.7-blue?logo=godot-engine)](https://godotengine.org/)
[![.NET](https://img.shields.io/badge/.NET-10-purple?logo=dotnet)](https://dotnet.microsoft.com/)

BrickVerse is a 3D multiplayer gaming platform built on top of the [Godot Engine](https://godotengine.org/), with a inital base forked from Polytoria licensed under MPL 2.0. It provides a set of tools for creating your multiplayer games, with server-client architecture, synchronized state replication and scripting powered by [Luau](https://luau.org/). Worlds can be published to [brickverse.gg](http://brickverse.gg/), which is accessible from Windows, macOS, Linux, and mobile.
